Stories 1080 × 1920 pour les infos pratiques et la billetterie, avec le sticker lien.

À fournir : date et horaires, lieu, prix, lien de billetterie, date de fin de prévente. Les exemples de l'aperçu sont fictifs (Velvet Edition, Le Salon, artistes, prix, horaires) : on les remplace par les vraies infos de l'édition.

- **Infos** : texture bordeaux, titre Anton 220 px, trois lignes (libellé `jaune`, valeur Archivo 600 48 px `creme`).
- **Relance** : fond `creme`, message court en Anton `velours`, une phrase de contexte. On ne parle de « dernières places » que si c'est vrai.
- **Sticker lien** : toujours au-dessus des 250 px libres du bas, sinon il passe sous le champ de réponse.
