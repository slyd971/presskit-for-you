Post 1080 × 1350 qui répond aux questions pratiques : quand, où, combien, quoi.

À fournir : date et horaires, lieu, prix, programme, lien de billetterie. Les exemples de l'aperçu sont fictifs (Velvet Edition, Le Salon, artistes, prix, horaires) : on les remplace par les vraies infos de l'édition.

- **Titre** : « INFOS PRATIQUES » en Anton 96 px `velours`.
- **Lignes** : libellé en `etiquette` `velours`, valeur en Archivo 600 44 px `charbon`, filet `charbon` de 3 px au-dessus de chaque ligne. Quatre lignes, toujours dans cet ordre : Quand, Où, Entrée, Au programme.
- **Pastille** : l'appel à l'action (« Billetterie : lien en bio »).
- Toujours sur fond `creme` : c'est le post qu'on relit, il doit être le plus lisible.
