Post 1080 × 1350 qui présente le programme d'une édition : la liste complète, puis un post par artiste.

À fournir : les noms et rôles des artistes (DJ set, live, karaoké), une photo par artiste pour le focus. Les exemples de l'aperçu sont fictifs (Velvet Edition, Le Salon, artistes, prix, horaires) : on les remplace par les vraies infos de l'édition.

- **Liste** : un nom par ligne en Anton 100 px `creme`, son rôle dessous en `etiquette`, un filet crème entre chaque ligne. Quatre lignes maximum ; au-delà, passer en carrousel.
- **Le karaoké compte comme un artiste** : « Le micro est à vous » a sa ligne, c'est ce qui distingue la Mif d'une soirée club.
- **Focus artiste** : photo à fond perdu sur la moitié haute, nom en Anton 200 px `charbon`, surtitre en `velours`.
- Fond : texture velours pour la liste, crème pour le focus.
