Post 1080 × 1350 qui annonce la date d'une édition avant tout le reste. Il sort environ trois semaines avant la soirée.

À fournir : la date, le nom de l'édition, une phrase sur le programme. Les exemples de l'aperçu sont fictifs (Velvet Edition, Le Salon, artistes, prix, horaires) : on les remplace par les vraies infos de l'édition.

- **Date** : Anton 360 px au format « JJ.MM », en `velours` sur `creme` ou en `creme` sur texture bordeaux.
- **Surtitre** : « SAVE THE DATE » en `etiquette` agrandie à 32 px.
- **Nom de l'édition** : `titre-xl`, un mot peut passer en `jaune` sur fond sombre.
- **Pastilles** : ville, et « Lieu dévoilé bientôt » si le lieu n'est pas encore annoncé.
