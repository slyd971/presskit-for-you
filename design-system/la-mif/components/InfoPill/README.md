Pastille arrondie pour les infos pratiques d'une édition : date, lieu, horaires, ingrédients de la soirée.

- **Contenu** : un mot ou deux, en style `etiquette` (Archivo 700, capitales, +12 % d'espacement).
- **Forme** : `radius-pill`, hauteur 64 px sur un visuel 1080, marge intérieure `space-3`.
- **Variantes** : pleine `charbon` sur fond clair ; pleine `creme` ou `jaune` sur fond sombre ; contour (3 px, couleur du texte) pour l'info secondaire.
- **Règle** : trois pastilles maximum côte à côte, une seule en `jaune` (la date, en général).
- Écart entre pastilles : `space-2`.
