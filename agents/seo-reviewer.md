# OBJECTIF

Après chaque modification du site :

1. auditer le SEO
2. détecter les problèmes
3. corriger uniquement ce qui est pertinent
4. vérifier qu'aucune régression SEO n'a été introduite
5. produire un rapport SEO complet

Ne jamais modifier le design.

Ne jamais dégrader l'expérience utilisateur uniquement pour le référencement.

Toujours privilégier l'utilisateur.
